# 2030 맞춤형 서울 주택가격 분석

서울시 부동산 실거래가와 한국은행 ECOS 거시경제 데이터를 결합해 주택가격 결정 요인을 분석하고, 2030 세대의 주거 의사결정 기준으로 정리한 데이터톤 프로젝트입니다.

- **기간** 2025.04 – 2025.05
- **구성** 팀원별 분석 노트북 · 최종 분석: 데이터톤_최종.ipynb (peumuoe)
- **이 저장소** 제가 작성한 최종 분석 노트북(`데이터톤_최종.ipynb`)

## 수행 역할 (peumuoe)
- 서울시 실거래가 데이터와 ECOS 거시경제 데이터를 수집하고 월 단위로 통합
- 결측치, 이상치, 고가 거래를 점검하고 정제 (약 101만 건 → 97만 건)
- 계약연월, 자치구, 주택유형, 면적, 건축연도 기준으로 파생변수 생성
- 자치구별, 주택유형별, 면적별 가격 분포를 시각화하여 가격 구조 비교
- 상관분석과 ANOVA로 변수별, 주택유형별 가격 차이 검정
- 예측 모델 6종을 5-fold로 비교하고 SHAP으로 주요 변수 해석
- 분석 결과를 2030 세대의 주거 의사결정 기준으로 재정리

## 데이터
- 서울시 부동산 실거래가 (2020.01 – 2024.12)
- 한국은행 ECOS: 기준금리, 실질 GDP, 주택담보대출, 선행종합지수 등
- 외부 변수: 인근 지하철역 수, 학교 수

## 주요 결과
| 모델 | R² (5-fold 평균, 약) |
|---|---|
| Random Forest | 0.94 |
| CatBoost | 0.83 |
| XGBoost | 0.83 |
| LightGBM | 0.77 |

- 주택가격은 금리, 물가 같은 거시 변수보다 면적, 자치구, 주택유형, 건축연도 같은 개별 특성의 영향이 더 크게 나타남
- 주택유형별 가격 차이가 통계적으로 유의함 (ANOVA, p < 0.001)
- 같은 서울 안에서도 조건별 가격 구조가 달라, 2030 세대에게는 조건별 비교 기준이 필요하다는 시사점 도출

## 한계
- 거래를 무작위로 나눠 검증했기 때문에, 같은 단지나 같은 시기의 거래가 학습 세트와 테스트 세트에 함께 들어가 성능이 실제보다 높게 나왔을 수 있음. 기간 기준 검증이 필요함
- 거시 변수는 같은 달의 모든 거래에 같은 값이 들어가므로, 개별 거래 단위 모델에서는 중요도가 낮게 나오기 쉬움
- 관찰된 상관관계이며 인과 관계가 아님

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, CatBoost, SHAP, Matplotlib, Seaborn
